极速安装 Claude Code + CC-Switch，接入 DeepSeek V4

前言

Claude Code 是 Anthropic 出的终端 AI 编程助手，但官方 API 国内访问不便。好消息是 DeepSeek V4 提供了 Anthropic 兼容接口，再配合 CC-Switch 这个可视化切换工具，你可以一键在多个模型之间切换——不用手动改 JSON、不用折腾环境变量，全程 GUI 操作。

本文记录从零安装 Claude Code → CC-Switch → 接入 DeepSeek V4 的完整流程。

三、安装 CC-Switch

CC-Switch 是一个基于 Rust + Tauri 开发的跨平台桌面应用，专门用来管理 Claude Code、Codex、Gemini CLI 等 AI 编程工具的 API 配置。核心价值：可视化切换模型，告别手动改配置文件。

下载安装

前往 GitHub Releases 页面下载对应平台的安装包：

👉 https://github.com/farion1231/cc-switch/releases

  • Windows：下载 .msi 安装包，双击安装
  • macOS：下载 .dmg 安装包
  • Linux：下载 .AppImage 或 .deb

Windows 用户注意：CC-Switch 依赖 Microsoft Edge WebView2。如果安装报错，先去 WebView2 官网 下载安装 Runtime，然后再装 CC-Switch。

四、获取 DeepSeek API Key

  1. 打开 DeepSeek 开放平台
  2. 注册/登录 → 进入 API Keys 页面
  3. 点击 Create new API Key
  4. 复制保存（格式 sk-xxxx，只显示一次）

需要先充值才能使用，DeepSeek 的价格非常便宜。

五、在 CC-Switch 中配置 DeepSeek V4

打开 CC-Switch，添加一个新的配置：

配置项 值
名称 DeepSeek V4（随便起）
API Key 你申请的 sk-xxxx
Base URL https://api.deepseek.com/anthropic
模型 deepseek-v4-pro[1m]

填好后点击保存，然后在首页启用这个配置。

模型说明：

  • deepseek-v4-pro[1m] — DeepSeek V4 Pro，开启 100 万 token 上下文窗口，适合大项目
  • deepseek-chat — 通用对话模型，响应更快
  • deepseek-reasoner — 推理增强模型，适合复杂逻辑

七、CC-Switch 的价值

以前切换模型要手动改 settings.json 或环境变量，改错了还不知道哪里出问题。CC-Switch 把这个过程变成了点一下：

  • 配好多个模型（DeepSeek、Claude、GPT……）
  • 想用哪个点一下「启用」
  • 重启 Claude Code 就生效了

八、在 VS Code 中使用（可选）

如果想在 VS Code 里用 Claude Code：

  1. 打开 VS Code 扩展商店
  2. 搜索 Claude Code for VS Code
  3. 安装后，左上角会出现 Claude Code 按钮
  4. 点击打开对话框即可

CC-Switch 的配置会自动生效，VS Code 里的 Claude Code 也会走 DeepSeek V4。

九、常用命令速查

命令 说明
claude 启动 Claude Code
claude --version 查看版本
/model 查看/切换当前模型
/clear 清屏
/undo 撤销上一步
/help 查看所有快捷指令
Ctrl + C / Ctrl + D 退出

十、常见问题

❌ CC-Switch 安装失败（Windows）

→ 缺少 WebView2，先安装 Microsoft Edge WebView2 Runtime

❌ claude: command not found

→ 执行 hash -r，或手动添加 PATH：

❌ npm 安装卡住

→ 确认已切淘宝源：npm config set registry https://registry.npmmirror.com

❌ 启动后提示连接失败

→ 在 CC-Switch 中检查 API Key 和 Base URL 是否正确，确认 DeepSeek 账户有余额

❌ 模型响应慢

→ deepseek-v4-pro[1m] 的百万上下文模式处理大量 token 时会稍慢，可以在 CC-Switch 中切换到 deepseek-chat 提速

总结

三件事搞定一切：

  1. 装 Claude Code → npm install -g @anthropic-ai/claude-code
  2. 装 CC-Switch → GitHub 下载安装，GUI 一键管理 API 配置
  3. 配 DeepSeek V4 → 在 CC-Switch 里填 API Key 和模型名，启用即可

CC-Switch 的核心价值是把「改配置文件」变成了「点一下」。以后想切回 Claude 官方模型、换 GPT-4、试其他国产模型，在 CC-Switch 里点一下就行，不用再折腾环境变量了。
