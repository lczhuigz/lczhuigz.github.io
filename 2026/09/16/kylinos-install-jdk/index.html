📋 三、命令速查表

步骤 命令
创建目录 sudo mkdir -p /usr/local/JDK
拷贝压缩包 sudo cp jdk-xxx.tar.gz /usr/local/JDK/
进入目录 cd /usr/local/JDK
解压 sudo tar -xvf jdk-xxx.tar.gz
编辑环境变量 sudo vim /etc/profile
加载配置 source /etc/profile
创建软链接 sudo ln -sf /usr/local/JDK/jdk-xxx/bin/java /usr/bin/java
验证版本 java -version

⚠️ 四、注意事项与 Tips

  1. 版本号按需替换
    本文中的 jdk-17.0.10 只是示例，实际请替换成你下载的版本。

  2. CPU 架构要匹配
    使用 lscpu 或 uname -m 查看架构，下载错误的包会导致无法运行。

  3. Linux 区分大小写
    /usr/local/JDK 和 /usr/local/jdk 是两个不同目录，配置时务必保持一致。

  4. 权限问题
    如果提示权限不足，请在命令前加 sudo，或切换到 root 用户执行。

  5. 只想给当前用户配置
    如果不想修改全局配置，可以改 ~/.bashrc 或 ~/.zshrc，然后执行：

  6. source /etc/profile 只对当前终端生效
    新打开的终端会自动加载；如果没生效，可以重新登录或重启终端。
